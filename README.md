# safe-path-evacuation
A smart evacuation and safe-path planning system that helps users identify safer routes and suitable evacuation centers during emergencies.
SafePath is a smart emergency evacuation system designed to help people identify safer routes and suitable evacuation centers during emergency situations.
The system uses digital mapping and route-planning concepts to provide users with clear information about safe paths, evacuation points, and emergency locations, helping people make faster and more informed decisions during critical situations.
